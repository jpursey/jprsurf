# `cmd:` properties

REAPER's commands, by command id: a number, such as "cmd:40029", or a named command id registered by an extension or script, such as "cmd:_SWS_ABOUT". A command with a toggle state is a toggle, which writing runs if the value changes, and any other command is an action. A command REAPER doesn't have is no property.
