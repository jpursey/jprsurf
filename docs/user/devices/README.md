# Device types

The hardware JPRSurf supports, each with a page of its widgets, by the names JPRSurf gives them.

| Device type | Description |
| --- | --- |
| [XTouch](XTouch.md) | The Behringer X-Touch, in Mackie Control (MC) mode, whose MIDI ports show as `X-Touch`. It has 8 channel strips, and a master section with the master fader, the timecode display, and the transport and navigation buttons. Every button has a light, apart from the pots'. |
| [XTouchExt](XTouchExt.md) | The Behringer X-Touch Extender, in Mackie Control (MC) mode, whose MIDI ports show as `X-Touch-Ext`. It has 8 channel strips, the same as the X-Touch's. |
